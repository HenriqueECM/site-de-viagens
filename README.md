# Projeto de Site de Viagens

Este projeto foi desenvolvido como parte do processo de aprendizado de Front-End, focando em praticar os conceitos básicos de desenvolvimento web e a utilização do **Flexbox** para layout e responsividade. O site tem como tema um portal de viagens, com informações sobre destinos, pacotes e atrativos turísticos.

## Tecnologias Utilizadas

- **HTML5**: Estruturação do conteúdo do site.
- **CSS3**: Estilização das páginas, com destaque para o uso de **Flexbox** para organização e responsividade.
- **Flexbox**: Aplicação de layouts flexíveis para garantir um design responsivo e organizado de forma simples e eficiente.

## Funcionalidades

### Layout Responsivo

O site foi projetado para se adaptar bem a diferentes tamanhos de tela, utilizando **Flexbox** para alinhar e distribuir os elementos de forma dinâmica.

### Página Inicial com Opções de Destinos

Apresentação de destinos turísticos com imagem, descrição e links para saber mais.

### Estilização com Foco na Experiência do Usuário

O design busca proporcionar uma navegação agradável e intuitiva.

## Objetivo do Projeto

Este projeto foi desenvolvido com o objetivo de praticar os fundamentos do desenvolvimento front-end, especialmente a estruturação e organização de layouts usando o Flexbox. A experiência foi focada em entender como construir interfaces responsivas e fluidas, além de aprimorar habilidades em HTML e CSS.
